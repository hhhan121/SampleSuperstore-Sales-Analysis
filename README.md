# SampleSuperstore 超市销售数据分析
> 数据科学课程实战项目，基于 Excel 完成销售数据分析

## 项目简介
本项目使用 SampleSuperstore 公开超市数据集，完成数据清洗、多维度透视分析，制作可视化看板，分析不同品类、地区、折扣对销售额和利润的影响，给出业务优化建议。

## 文件说明
- SampleSuperstore.xlsx：源文件，包含清洗后原始数据、5 张透视表、Dashboard 看板
- dashboard.png：看板预览图

## 分析流程
1. 数据清洗：去除重复、清理空值、处理文本空格，保证透视表正常统计
2. 多维度透视分析：商品大类、子品类、地区、发货方式、折扣-利润
3. 可视化：条形图，对比销售额与盈利情况
4. 整合看板，汇总全部指标

## 结论
部分商品存在高折扣带来亏损，需要控制折扣策略；不同区域销售差异明显，可以针对性运营。
